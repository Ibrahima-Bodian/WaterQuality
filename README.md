# WaterQuality

Projet de data science sur la qualite de l'eau du robinet et la pression agricole en France.

## Contenu

- `CONSIGNE/` : consignes du projet.
- `DATAS/data_pesticides/` : donnees consolidees sur les indicateurs de pression phytosanitaire.
- `DOCX/` : supports de reference et de presentation.
- `LIVRABLES/` : documents produits et scripts du projet.

Les donnees brutes d'analyses d'eau sont volontairement exclues de Git dans `DATAS/data_eau/` : elles representent environ 20 Go et doivent etre recuperees depuis leur source officielle. GitHub n'est pas adapte au stockage de ces fichiers volumineux.

## Etat du projet

La phase 1 documente les besoins utilisateurs et le cadrage de l'etude. Le script `LIVRABLES/Untitled-1.py` est un point de depart a completer.
